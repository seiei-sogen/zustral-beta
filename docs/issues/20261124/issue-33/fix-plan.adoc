= issue #33 の修正計画: 一時ファイルを残すオプションと、`error.html` を出すオプションを足すか

== 目的

issue #33 の残りは、判断が1つである。一時ファイルを残すオプションと、`error.html` を出すオプションを、足すか。
既定の振る舞い（一時ファイルを消す、`error.html` を書かない）は、PR #170 で直してある。

終わりの条件は、判断を記録して、issue を閉じることである。

== 判断

*どちらのオプションも足さない。*

* 生成した C を見たいときは、`--target-type=c --output=x.c` で、好きな場所に書き出せる。一時ファイルを残すオプションは、これと同じことをする2つ目の方法になる。
* エラーを機械で読みたいときは、`--error-format=json` がある。`error.html` を書くコードは、もう残っていない。オプションを足すと、HTML を組み立てるコードを書き直すことになる。
* README の「ベータ版ではやらないこと」に、エラーメッセージの改善がある。ベータ版に引き継ぐ価値のある機能ではない。

所有者が違う判断をしたら、issue を開き直す。

== 現状

`docs/issues/20261124/preliminary-investigation.json` の `next_issue` に、確かめたコマンドと結果がある。

* 成功したコンパイルも、失敗したコンパイルも、一時ディレクトリとカレントディレクトリに何も残さない。
* `error.html` と `calltree.html` を書くコードは、`lib/`、`cli/`、`bin/` にない。
* `.gitignore` に `error.html` の行が残っている。

== 変更

* `.gitignore`: `error.html` の行を消す。書くコードがないので、要らない。
* `README.md`: 「いまの進み具合と、次にやること」節から #33 を消し、判断を記録する。

コンパイラのコードは変えない。

== テスト

足さない。振る舞いは変わらない。
`test-programs/cli/047-html-characters-in-file-name` が、`error.html` を書かないことを、既に固定している。

== 確認

CI の検査への影響はない。`tools/refactoring/run-every-ci-check-locally.sh` を通す。

== 範囲外

* オプションを足すこと。

== セルフレビュー

issue の本文に照らして見直した。

* 「一時ファイルは、C のコンパイルが終わったら消す」: 直っている。実行して確かめた。
* 「調査のために残したいときだけ、オプションで残す」: 足さないと判断した。理由は「判断」の節にある。
* 「`error.html` と `calltree.html` は、既定では書かない」: 直っている。
* 「オプションで出力先を指定したときだけ書く」: 足さないと判断した。
* 「テストを並行して走らせると、同じ場所に同じ名前で書き合う」: `Filename.temp_file` が、コンパイルごとに別の名前を作る（`cli/CliEngine.ml`）。カレントディレクトリには書かない。

見直しで直したこと: `.gitignore` の `calltree.html` は、もう行がなかった。変更の節から外した。
