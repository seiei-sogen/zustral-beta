Shows that the exit status of a failed compilation is 255 also when the compiler cannot write the error: the runner gives it `/dev/full` as stderr (`stderr-is-the-full-device.txt`). Flushing stderr when the process ends raises `Sys_error` then. Since issue #174 every error is written in the handler of `Cli.main`, where nothing catches that exception, and the status was 2, the one of an uncaught exception. `Cli.main` now closes stderr before it ends the process.
