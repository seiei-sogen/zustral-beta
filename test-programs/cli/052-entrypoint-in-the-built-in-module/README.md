An entrypoint in the built-in module `Zustral.Pervasive`. The error has the position of the function in the source of the built-in module, which is not one of the files on the command line. The file name is the path of that source in the repository of the compiler, `lib/builtin/Pervasive.zum`, the lines are those of the file, and the error shows them (lib/BuiltInModuleSources.ml, issue #172). Before, the built-in modules were parsed with the empty file name and one line too many, and the error had no source context.
