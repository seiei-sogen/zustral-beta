An error about a borrow in the value assigned to a path: `wantsStatic(&t)` passes a reference whose region is not `Static`. The borrow of `&t` is anonymous, so the message names its region by the variable the borrow is of, `region of the borrow of t` (issue #178). Before that, the message had the name the compiler gave the region, `_tmp_region_2` (the borrow of the target `s` was `_tmp_region_1`); and before issue #144, the number the type checker gave the region, 4, which depended on the order it numbered the regions in.
