Test that a method of a typeclass mentions the typeclass's type parameter in its parameters or its return type (issue #175). A call of a method finds its instance by the type in the place of that parameter, so a method that does not mention it cannot be called. The error is where the typeclass is declared. Before, the declaration passed, and every call of the method failed with `No binding for this parameter: T` (lib/TypeCheckExpr.ml, bound_type).
