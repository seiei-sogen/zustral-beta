Pins the numbers of the tags in the generated C to the order the cases are declared in: the first case is 0, the next 1, and so on (issue #39). The program reads the tag of each case with an `@embed` in an unsafe module and prints it. It covers a union with one case, with three and with four cases, a union imported from another module, a union declared as an opaque type in an interface and defined in the body, a generic union with two monomorphs (`Choice[Int32]` and `Choice[Bool]`), and the built-in `Option` with two monomorphs. Before, the cases were numbered from the last to the first: `Red` was 2. A runtime that takes a case of a union as a number, such as the rounding modes of the decimal work, needs the declared order.
