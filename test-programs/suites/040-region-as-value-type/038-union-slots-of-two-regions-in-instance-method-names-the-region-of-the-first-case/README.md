Pins which region the error names when the cases of a union hold different region type parameters of an instance method: the region held by the case the union declares first (lib/ExtractionPass.ml, region_held_by_value). The method passes `S` for the parameter of the first case and `R` for the parameter of the second, and the error names `S`. Before issue #39, it named the region held by the case the union declares last, `R`.
