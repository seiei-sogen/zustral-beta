Shows that the error for an entrypoint that names no declaration of its module points at the name of the module in its body file, when the module also has an interface file (issue #87). The entrypoint is `Test:main`, and the module declares only `start`. The function would be defined in the body, so the error points at `Test` in `module body Test is`, in `Test.zum`. Before, the error had no position, because the environment kept no position for a module.
