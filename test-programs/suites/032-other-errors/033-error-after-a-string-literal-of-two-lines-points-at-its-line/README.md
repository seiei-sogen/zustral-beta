Shows that an error after a string literal that spans two lines points at the line it is on (issue #172). The `let` with the type error is on line 5. Before, the lexer did not count the line break inside the string literal (lib/Lexer.mll, `read_string`), so every position after it was one line too early, and the error was reported on line 4. The same count gives the right position to the error of a string literal that the file ends inside (`019-lexer-string-end-of-file`).
